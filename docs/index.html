Request pipeline

Client›FastAPI proxy›Guards · TTL policy›L1 exact hash›Embed›Vector search (Redis / Qdrant)›Similarity ≥ threshold ?›HIT → replay/MISS → LLM → store

Extras: single-flight request coalescing, SSE replay for streaming clients, scope isolation per model + system prompt, adaptive TTL by temperature, freshness guard for time-sensitive prompts, Prometheus + Grafana observability.
